# My Simple Calculator 📱

A powerful and simple Android Calculator app built with Java.

## Features ✨
* Basic arithmetic: Addition, Subtraction, Multiplication, Division.
* Advanced operations: Power (x^y), Square Root (√), Percentage (%).
* Mathematical constants: Pi (π).
* Clean and responsive UI.

## How to Install 📥
1. Open this repository on your Android phone.
2. Go to the `release` folder.
3. Click on **[Calculator.apk](https://github.com/ritu623/MySimpleCalculator/raw/main/release/Calculator.apk)** to download it.
4. Open the downloaded file and install it (you may need to "Allow from this source" in settings).
